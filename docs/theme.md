# 博客明暗主题

当前主题切换入口已在 Header.astro 中注释，ThemeInit.astro 固定设置浅色，
global.css 的自动跟随系统规则也已注释。旧的浏览器偏好保留但不再读取。
下文描述保留的主题实现，恢复功能时需同时恢复入口、初始化和系统 CSS 规则。

导航栏主题选择器支持浅色、深色和跟随系统，默认跟随系统。
选择保存在访客浏览器 localStorage 的 `kvxin-blog-theme`，不写入数据库，
不改变其他访客或管理后台的主题。

ThemeInit 在页面绘制前设置 html 的 data-theme，避免先显示浅色再切为深色。
Astro ClientRouter 页面切换前同步目标页面主题，切换后同步选择器状态。
跟随系统会监听系统主题变化；浏览器多个标签页之间也同步选择。
存储被禁用时仍可以在当前页面切换。无 JavaScript 时按系统偏好显示主题。

颜色通过 global.css 的 CSS 变量定义，导航、正文、卡片、代码块、表格和
图片预览使用同一套语义颜色。图片本身不反色。修改样式后通过后台发布管理
构建上线，保留数据库文章；不要用本地内容发布脚本覆盖 CMS 内容。
