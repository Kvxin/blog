# Features

auth 实现管理员登录、会话检查和退出；RequireAuth 保护所有后台业务页面。
dashboard 提供实际服务状态。posts 和 moments 实现分页、搜索、状态筛选、
新建、编辑、删除，提交共享 contracts 校验，并用 updatedAt 检测编辑冲突。

文章支持多个语言版本和 Markdown 预览。预览不执行 HTML/MDX，也不自动请求
正文中的其他远程图片。素材上传已接入七牛云，文章封面、碎碎念配图和正文
都可使用素材选择器。分类标签支持 CRUD、搜索、关联数量、文章关联和筛选。
发布管理支持触发构建、任务状态、日志和当前版本；站点设置仍为占位功能。
